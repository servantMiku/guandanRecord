# Bug 修复计划：荣誉门槛与数据导入导出

## 概述

修复两个核心 bug：
1. **荣誉门槛保存失败**：保存按钮样式缺失（字体黑色），且保存逻辑可能异常
2. **数据导入导出**：微信小程序端导出/导入流程不顺畅，需要优化文件读写和交互流程

平台：**mobile**（微信小程序）

---

## 技术方案

| 维度 | 选择 | 理由 |
|------|------|------|
| 存储方案 | 继续使用 Taro.saveFile + wxfile | 微信小程序标准文件 API |
| 导出格式 | JSON（紧凑格式） | 导入时解析稳定，体积小 |
| 交互方案 | Taro.showModal + Taro.setClipboardData | 微信原生弹窗，用户体验一致 |
| 字体修复 | CSS 补充 `.threshold-save-*` 类 | 与现有按钮风格统一 |

---

## 功能模块

### 模块 1：荣誉门槛保存修复

**问题清单**：
- `profile/index.css` 缺少 `.threshold-save-btn` 和 `.threshold-save-text` 样式
- 按钮字体显示为黑色（继承默认），应与其他按钮统一为白色
- 保存 API 调用需验证是否正常

**修复要点**：
- 补充 CSS 样式，与 `.backup-btn` 风格统一（渐变绿背景 + 白字）
- 验证 `POST /api/config` 调用及错误处理

### 模块 2：数据导出优化（微信小程序）

**问题清单**：
- 导出后文件路径为 `wxfile://usr/...`，用户无法直接访问
- 需要复制文件路径或提供可读的方式让用户获取数据

**修复要点**：
- 导出成功后使用 `Taro.setClipboardData` 复制 JSON 内容到剪贴板
- 提供清晰的操作指引：复制后粘贴到微信文件传输助手保存
- 移除冗余的 TXT 文件生成，简化流程

### 模块 3：数据导入优化（微信小程序）

**问题清单**：
- `chooseMessageFile` 需要用户先发送文件到微信聊天
- 流程复杂，用户可能不知道如何使用

**修复要点**：
- 保持 `chooseMessageFile` 方案（微信小程序标准方式）
- 优化引导文案，告诉用户"请先将备份文件发送到微信文件传输助手"
- 导入成功后自动刷新页面数据
